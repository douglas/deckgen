# Security

deckgen renders specs into HTML, so the issues that matter most are ways a spec can inject script or markup into a deck, or leak data the checks should have caught.

Please report a vulnerability privately, by email to code@douglasandrade.com or through [GitHub's private vulnerability reporting](https://github.com/douglas/deckgen/security/advisories/new), not in a public issue. Include a small fictional spec that reproduces it.

Only the latest release gets fixes.
